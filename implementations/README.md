# Implementations

This folder contains community-built implementations of the CDRS architecture.

---

## How to Add Yours

1. Create a folder: `implementations/<your-github-handle>/`
2. Add your code and a `README.md` explaining:
   - Language and framework used
   - Which pillars are implemented
   - How to run it
   - What works and what doesn't yet
3. Open a Pull Request using the Implementation template
